请将 TradingView Charting Library 放在此目录下。

1. 访问 https://www.tradingview.com/charting-library-docs/
2. 获取 Charting Library（需注册/申请）
3. 将解压后的 charting_library 文件夹内的所有文件放到本目录
4. 确保存在文件: charting_library.js

最终目录结构示例:
  public/charting_library/
    charting_library.js
    charting_library.standalone.js  (或类似)
    themed.css
    ... 其他库文件
